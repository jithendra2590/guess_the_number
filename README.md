# Guess The Number — Interactive Number Guessing Game

An interactive browser game where the player guesses a randomly generated number between 1 and 100. The game gives instant feedback after every guess — "Too high" or "Too low" — until the player finds the correct number, with a success message on a correct guess and validation for invalid inputs. The interface is responsive and styled with Bootstrap for a clean, mobile-friendly experience.

## Live Demo

https://jithu2590gtn.ccbp.tech/

## How to Play

1. Enter a number between 1 and 100.
2. Click Check.
3. Follow the hints (Too high / Too low) until you guess it right.
